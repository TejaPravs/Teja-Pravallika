## 📌 Featured Projects

### 🎭 Emotional Tone Prediction using GPT-4o-mini & RoBERTa

An LLM-powered multi-label emotion classification system that predicts emotional tones from movie descriptions using a teacher-student learning framework.

**Highlights**
- Processed 15,000 movie overviews from Kaggle's Movies Dataset.
- Generated emotion labels using GPT-4o-mini as a teacher model.
- Fine-tuned RoBERTa as the student model for multi-label classification.
- Classified content across 29 emotional tones.
- Addressed class imbalance through targeted sampling with replacement.
- Improved model performance by increasing the F1-score from **0.6628 → 0.876**.
- Conducted precision-recall analysis to improve performance on rare emotional tones.
- Achieved **95.5% test accuracy** while significantly improving recall and precision.

**Tech Stack**

Python PyTorch RoBERTa GPT-4o-mini Hugging Face Scikit-Learn
